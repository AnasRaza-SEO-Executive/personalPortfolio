# Anas Raza — SEO Specialist Portfolio

Dark, modern SEO portfolio (Dribbble-inspired) with multi-page routing.

## Pages

| Route | Content |
|-------|---------|
| `/` | Home — Hero, intro, about me, stats, companies, clients |
| `/portfolio` | Results by category with expandable cards |
| `/case-studies` | Detailed case studies |
| `/services` | SEO services offered |
| `/resume` | Work history & skills |
| `/contact` | Contact info + form modal |

## Add your images

See `public/images/README.md` for folder structure. Until images are added, placeholders show initials.

## Customize content

Edit `src/data/content.ts`:

- Contact email, phone, social links
- Client names (replace Client 1–11)
- Company dates/roles
- Portfolio screenshots paths
- Case study copy

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173
